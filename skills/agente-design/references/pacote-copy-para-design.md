# Pacote para o Design (o que o Copywriter entrega)

O Copy só encaminha para o Design com o pacote completo. O Design confere item por item; o que faltar volta para o Copy (ou para o usuário) com a lista exata.

```
PACOTE PARA O DESIGN
Projeto: [cliente]
Peça: [criativo de anúncio | carrossel | stories | thumbnail | página | Hotmart | outro]
Objetivo: [atrair | captar | vender | lembrar] — Público: [frio | morno | quente]
Onde roda: [plataforma + posição] — Formatos: [ex.: feed 1080x1350, stories 1080x1920]
Campanha / nomenclatura: [ex.: BLACK-NOV/26 · CAPTACAO · F]

Textos:
- Cabeçalho: [opcional]
- Selo: [ex.: AO VIVO · 24/11]
- Headline: [texto; **palavra** = destaque]
- Apoio: [texto]
- CTA (botão): [texto]
- Rodapé: [opcional]
(Carrossel/stories: repita por tela — Tela 1 capa ... Tela final com CTA único)

Prova e oferta que PODEM aparecer: [...]
NÃO pode aparecer: [datas internas, bônus secreto, promessas não autorizadas]
Imagem: [foto real no Banco de imagens: nome do arquivo | sem foto]
Variações pedidas: [quantas e o que muda]
Observações de marca: [se diferente da Identidade visual]
```

Página: em vez de "Textos", a copy completa por seção (hero, problema, solução, prova, oferta, FAQ, CTA final, rodapé), o formulário (campos e destino) e o que acontece depois do envio.

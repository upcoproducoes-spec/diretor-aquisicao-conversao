# Qual skill chamar (e em que ordem)

Leia o SKILL.md da skill antes de usar. Use só o que o trabalho pede.

## Web (site, landing page, página do Up)
1. `design-taste-frontend` — Design Read, mostradores, anti-genérico. Sempre primeiro.
2. `ui-ux-pro-max` — sistema (paleta, tipografia, padrões de UX); DESIGN.md em projeto grande.
3. Direção estética (uma, pelo Design Read): `high-end-visual-design`, `minimalist-ui`, `industrial-brutalist-ui`, `stitch-design-taste`.
4. Construção: `frontend-design`; `ui-styling` só com shadcn/Tailwind. Páginas do Up são HTML único.
5. Referência visual antes de codar (página grande): `imagegen-frontend-web` / `image-to-code`.
6. Melhorar o que existe: `redesign-existing-projects`.
7. Revisão: `impeccable` (critique/audit/polish) + `design:accessibility-review` + `revisao.md`.

## Criativos, conteúdo, YouTube, Hotmart (estáticos)
1. `banner-design` — requisitos, direção de arte, tamanhos, regras.
2. Identidade visual do projeto (Up).
3. Produção: bloco `peca` (formatos ig_feed, ig_square, ig_story, ad_landscape, yt_thumb, hotmart_banner, hotmart_checkout, hotmart_avatar, hotmart_vitrine_v, hotmart_vitrine_h, hotmart_popup). Fora do editor: HTML/CSS + Chrome headless (`--headless=new --default-background-color=00000000 --window-size=W,H --screenshot`).
4. Revisão: `revisao.md` (+ `ads-creative`, só a parte de criativo, para anúncio pago).

## Marca e logo
- `brandkit` (métodos de logo: monograma, ação do produto, fusão de metáfora, espaço negativo, geometria; quadro da marca).
- `design` (logo, identidade corporativa), `brand` (guia e tokens), `design-system` (tokens primitivo → semântico → componente).
- Logo com nome: preferir versão tipográfica (SVG) quando a grafia precisa ser exata; IA para símbolo e exploração.
